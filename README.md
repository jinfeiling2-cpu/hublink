# Hublink

Hublink 用来整理个人信息、方向、项目、经历、作品和社交账号，并把它们之间的关系放在一张图里。访客可以按简历、时间、重要性、规模、联系或三维坐标浏览；进入一个项目后，还可以查看系统结构与实际运行过程。

当前版本是本地运行的 Next.js 原型，使用 SQLite 保存图谱，并提供公开阅读页、管理后台和 GitHub 仓库快照同步。它尚未部署成线上网站，也没有接入托管数据库与管理员身份系统。个人履历和其他作品尚未录入。

第一个项目案例是 Hublink 本身：[/project/hublink](/project/hublink) 说明当前系统由哪些部分组成、访客阅读和后台写入怎样经过代码，以及哪些问题需要项目参与者继续梳理。目标架构与分阶段计划见 [docs/搭建规划与理解记录.md](docs/搭建规划与理解记录.md)；当前原型的登记表说明见 [docs/框架说明.md](docs/框架说明.md)。

关于项目、经历和产出如何同时服务个人总结、简历阅读、深度探索、AI 读取和共同学习，见 [docs/多读者与简历验证设计记录.md](docs/多读者与简历验证设计记录.md)。这份记录暂不代表已经完成简历生成；载入更多真实资料后再进行第二波调整。

当前收集箱材料的类别、完成阶段、来源和发布范围已经分开记录，见 [docs/材料分层与公开发布流程.md](docs/材料分层与公开发布流程.md) 和 [docs/公开内容候选清单.md](docs/公开内容候选清单.md)。游戏和世界观文件目前是个人构思档案，不应被描述成已完成项目。

后续提供的简历、个人规划和项目经历概述可先放入本地 `资料收集箱/`；分类和隐私说明见 [docs/资料收集箱使用说明.md](docs/资料收集箱使用说明.md)。该目录已从 Git 跟踪中排除，适合暂存个人原始材料。

## 运行

```bash
npm install
npm run dev
```

开发服务器在 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

后台在 `/admin`。没有设置 `ADMIN_PASSWORD` 时，开发口令是 `dev-hublink-admin`。复制 `.env.example` 为 `.env.local` 后可以改口令。私有 GitHub 仓库的拉取还需要 `GITHUB_TOKEN`。当前后台仅供本地开发原型使用，不应作为公开部署的认证方案。

图存在本地的 `data/hublink.sqlite`，这个文件不进入仓库。首次启动会写入「Hublink」这套讲解。已经改过的点不会被覆盖；删掉的编号会在下次启动时补回。

```bash
npm test
npm run lint
```

## 当前原型

- 简历概览、关系图、按时间 / 重要性 / 规模 / 联系 / 活动种类浏览、三维网格、项目 / 经历 / 社交关系深入
- 后台：节点、连线、公开与个人的切换
- GitHub 仓库快照。公开仓库默认公开，私有仓库默认个人；再次拉取不改写正文和可见性
- 小红书只登记主页和你写的说明，不拉取笔记
- `GET /api/graph` 只返回公开节点
- Hublink 项目案例：系统职责、阅读 / 编辑 / 同步流程和理解练习

线上网站、托管数据库、正式管理员认证、编辑历史和数据备份尚未实现。
