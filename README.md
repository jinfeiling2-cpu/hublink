# Hublink

一张用来阅读一个人的图。节点记下工作、经历、方向和账号，连接记下它们如何组成、如何证明、如何前后相续。阅览框架只负责把这张图排开。

这一版先放入一个公开项目「Hublink」：用内部的点讲清这个网站如何搭建、一次访问如何走，并留出「留白」。其他履历和作品还没有写。类型、连接、维度、阅览、公开范围和来源规则已经可以运行。

完整设计写在 [docs/框架说明.md](docs/框架说明.md)。运行中的登记见站点里的「框架」页。

## 运行

```bash
npm install
npm run dev
```

开发服务器在 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

后台在 `/admin`。没有设置 `ADMIN_PASSWORD` 时，开发口令是 `dev-hublink-admin`。复制 `.env.example` 为 `.env.local` 后可以改口令。私有 GitHub 仓库的拉取还需要 `GITHUB_TOKEN`。

图存在本地的 `data/hublink.sqlite`，这个文件不进入仓库。首次启动会写入「Hublink」这套讲解。已经改过的点不会被覆盖；删掉的编号会在下次启动时补回。

```bash
npm test
npm run lint
```

## 这一版有什么

- 阅读入口，以及十种阅览：十几秒印象、按时间 / 重要性 / 规模 / 联系 / 活动种类、三维网格、项目深入、经历深入、社交深入
- 后台：节点、连线、公开与个人的切换
- GitHub 仓库快照。公开仓库默认公开，私有仓库默认个人；再次拉取不改写正文和可见性
- 小红书只登记主页和你写的说明，不拉取笔记
- `GET /api/graph` 只返回公开节点
